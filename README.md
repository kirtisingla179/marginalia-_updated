# 📚 Marginalia

**Marginalia** is a student blog platform where students can **read, write, and share ideas, experiences, and knowledge**.

## ✨ Features

* 📝 Student blogs & articles
* 📖 Read and explore content
* 📱 Mobile-first & responsive design
* 🎨 Clean, student-friendly UI

## 🛠️ Tech Stack

**Current:** HTML5, CSS3
**Future:** JavaScript, React.js

## 🚀 Vision

To create a simple platform where students can **express themselves, share knowledge, and learn from each other**.

---

**Built for students, by students.**
